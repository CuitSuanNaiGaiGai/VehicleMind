# VehicleMind

VehicleMind is an intelligent vehicle AI system that integrates
cabin perception, driving perception, path planning, and
human-machine interaction.

> 🚧 This project is under active development.

## Roadmap

### Phase 1 — Cabin Perception

- [ ] Face detection
- [ ] Facial landmark estimation
- [ ] Head pose estimation
- [ ] Eye-state analysis
- [ ] Yawn detection
- [ ] PERCLOS estimation
- [ ] Driver fatigue detection
- [ ] Driver distraction detection
- [ ] Real-time visualization

### Phase 2 — Driving Perception

- [ ] 2D object detection
- [ ] Lane detection
- [ ] Drivable-area segmentation
- [ ] Semantic segmentation

### Phase 3 — Planning

- [ ] CARLA integration
- [ ] Global route planning
- [ ] Local path planning

### Phase 4 — Intelligent HMI

- [ ] Intent recognition
- [ ] Vehicle function calling
- [ ] Dialogue system
- [ ] Context-aware recommendation
