# A6：A5 合入后的在线 Agent 回归证据包

状态：按用户“继续推进、无需逐项确认”的授权直接实施。

## 问题与目标

A5 已合并，但公开报告里的 Qwen/GLM 40 场景结果来自 A5 之前的代码。需要用同一组冻结场景补一份当前版本证据，并让浏览者能看懂“Agent 做对了什么、哪里失败、运行代价如何、结果能否追溯”。这是简历展示闭环，不是构建新的通用评测框架。

## 方案选择

1. **只拼接历史报告**：最快，但不能证明 A5 后版本的实际在线行为，排除。
2. **复用现有 runner，增加轻量 provenance 与报告汇总**：Qwen/GLM 各跑相同 40 个冻结场景、每场景 3 次；机械评分和 AI 辅助语义复核保留逐条失败。A3 RAG、A4 记忆、A5 恢复仍分别引用其本来分母，不合成总分。采用此方案。
3. **重构成跨阶段统一分数或新评测平台**：会抹平不同阶段证据口径并增加维护量，排除。

## 外发与证据边界

- 在线 Agent 请求和语义复核仅使用仓库内 SHA-256 冻结的合成场景、公开提示/工具协议及合成模型回复；不使用或上传本机舱内/舱外视频、帧、个人信息、API 密钥、本地原始回放或运行路径。
- 用户已授权两家 API 及费用；在线工作限定在这批合成回归内容。若检查中发现冻结数据含个人信息或任何本机媒体内容，停止该批调用并保留已有离线工作。
- 40 个场景 × 每模型 3 次，仍是 40 个不同场景，120 个相关 trial；不得把重复运行说成 120 个独立样本。
- AI 语义审查不是人工审定。`needs_review` 不是成功。失败、异常、待审查均保留在分母与报告中。
- 优化前后比较使用同一场景、rubric 与当前语义审核协议。历史 v3 语义审核值只作为历史基线，不能直接与 v4 结果宣称同口径；需对旧批次原始合成 trace 用当前审核协议重新评阅，且不改写原始目录。
- 不把不同任务类型的 A1–A5 指标合成一个“综合 Agent 成功率”。
- 历史 trace 未记录的执行预算保持未知；已知预算必须相同。历史预算不完整时，仅作描述性并列展示，变化差值为 N/A，不宣称性能提升由代码改动导致。
- 审核输出解析失败计为失败并保留 usage 与错误证据；无法核算的历史调用使该批审核费用为 N/A，不能当作零费用。
- 成本按两家 API 对应官方 endpoint/地域/计费档位及观测到的 input/output token 估算；若单价或 cache/长上下文档无法由官方来源确认，费用显示 N/A。价格来源及检索日期写入报告。

## 实现范围

1. 扩展在线 batch provenance，记录源代码 commit、冻结 manifest/rubric 摘要、模型、温度、时限和 Agent 预算；不记录密钥。
2. 增加小型汇总器与中文 `summary.json`、Markdown、HTML 报告：按模型及版本分别报告机械成功、AI 语义审核、工具/参数/状态、API 异常、p50/p95、请求与 token；按指标提供分子/分母、审核类型、源 run/trace 哈希。
3. 生成同口径历史前测与 A5 后复测对照；并列而不合并 A3 Recall/Citation、A4 事件查询、A5 确定性恢复证据，清楚标注其各自来源和限制。
4. 在线运行 Qwen 与 GLM，各 40 场景 × 3 次；以 Qwen 当前审核协议复核两组优化前后合成回答；保留所有 trial 及失败证据在本地忽略目录，不提交 raw trace。
5. 更新 A6 报告、README/TODO 对应状态和复现命令，只有产物与哈希/评分闭环真实完成后才勾选。

## 验收

### 既有 TODO 的子集指标口径

只复用已冻结 rubric 的逐 trial 语义决定，不新增 judge 或改分。相比另造评测平台或只给一个总分，选择小型纯函数生成可重算的描述性子集摘要：

- Context Grounding Correctness（上下文依据子集语义通过率）：固定 C01–C06、R01–R06、X01–X10，共 22 题 × 3 次 = 66 trial，分子为该题完整 rubric 的语义 pass。
- stale/UNKNOWN Handling（过期/未知子集语义通过率）：固定 C04、C05、R06、X06、X07、X08，共 6 题 × 3 次 = 18 trial，同样使用语义 pass。
- 三次重复波动：每个 trial_index 分别统计 40 题的 Task Success；只描述重跑波动，不将其当成独立实验的置信区间。

这些是对既有运行的事后描述性切片，不是新冻结的盲测，也不是逐事实的准确率；子集重叠，不相加。摘要保存 case ID 与分子分母，Markdown/HTML 同步展示。实现隔离在小模块，不扩大主汇总文件。小规模单元夹具按实际交集计数，正式完整集的分母由完整批次校验保证。

- 冻结 manifest 的 40 个唯一 case 均出现且每 case 每模型恰有 trial 1/2/3；旧/新 run、trace 与审核结果均通过哈希/身份校验。
- 机械与语义分项、待审核数、异常数和分母均能从 run/审核记录重算；不丢失败，不将 `needs_review` 计为语义成功。
- HTML 中文可读、无模型输入全文/本机绝对路径/密钥，并明确 A3/A4/A5 不共用分母。
- 本地 API 运行不落入 Git；文档只引用可公开复现的冻结场景与脱敏汇总。
- 专项测试、全量离线测试、ruff、mypy、大小策略和 Git diff 检查通过，再提交 PR，经 CI 合并并同步本地 main。

## 不在范围

人工标注或感知准确率、消融实验、上传媒体/运行 trace、真实车机执行、在线 SLA 声明、将异质指标相加、演示视频制作。
