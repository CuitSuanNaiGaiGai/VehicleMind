# VehicleMind Agent 决策依据与目标变更设计

基线：`main` / `1d38e06`。本设计只读检查了生产代码、README、todolist、A6 报告及相关测试；没有调用在线服务、读取 `.env` 内容或修改生产文件。

## 独立判断

已有 A1–A6 已经提供质量感知上下文、受限计划、确认门、检索与记忆。新增框架或重复 RAG 不能直接解决当前公开失败。建议用两个紧密相关的任务完善 **事实如何进入决策，以及决策如何与工具结果一致**。

## 已复现的根因

| 案例 | 在当前代码上执行的结果 | 判断 |
|---|---|---|
| X08 | `detect_topics('结合我现在的状态和道路情况说说。')` 返回 `road, vehicle`，没有 `driver` | “我的状态”不命中驾驶员关键词；道路耦合规则没有选入舱内。模型遗漏高风险之前，输入已丢失该证据。 |
| C04 | 实际上下文含 `presence=ABSENT`、`quality_status=KNOWN`、闭眼/哈欠 0，却没有 `state/risk=UNKNOWN` 的质量说明 | `include()` 删除不可用字段，之后 `attach_field_evidence()` 只遍历保留字段，未知原因一起消失。`ABSENT` 仍需明确解释为“未检测到”，不能推断真实驾驶座无人。措辞问题是否解决要靠实际模型复测。 |
| M03 | `requested_target()` 返回 `河滨服务区，请重新搜索；找不到就不要导航`，与两个已返回候选的匹配均为 False | 用户的约束从句被并入实体名称，再与 alias 严格全串比较。不是地图没找到河滨，也不是缺少知识检索。 |

此外，`run_turn()` 在目标变更后只检查是否存在 pending，然后仍可采用模型自由文本；模型可以与已成功匹配的结果矛盾。目标变更的回复应直接根据已执行的搜索、唯一匹配与 pending 生成有限的结果说明。

## 任务一：质量感知的决策简报

保留现有 `ContextSelector` 和字段证据，不另建事实数据库。新增一个小型纯函数模块，从本轮选入的上下文和字段质量产生结构化 `required_points` 与 `unavailable_fields`，附在现有上下文消息后。简报是明确的系统规则结果，不是模型思维链，也不自动证明模型已经遵守。

- 跨域驾驶状态问法补齐驾驶员主题；普通问候仍不注入动态上下文。
- 一个域过期不删除另一域仍有效的事实。高风险与疲劳只能引用当时 `KNOWN` 的字段。
- `ABSENT` 产生 `DRIVER_NOT_DETECTED` 说明；未知 state/risk 产生未知说明，旧值不回流。
- 简报只提示本轮应覆盖的事实与限制，不添加阈值、医学推断、未经授权工具调用或额外 LLM 回合。
- 中文报告展示实际请求里的简报，以及字段未采用的原因。历史报告没有简报时正常显示“未记录”，不能事后推断。

## 任务二：目的地实体解析与工具结果一致性

只支持有明确前缀的现有改目标意图。目的地与后续逗号/分号从句分开，保留用户原文供 trace 审核。候选匹配只认本次成功工具结果中的 `poi_id/name/display_name_zh/aliases` 精确规范化值；不使用子串、编辑距离、LLM 猜测。同名多个规范 POI 属于歧义，要求补充信息。

搜索成功且唯一匹配时创建新的一次性 pending，并直接回复规范中文名称、尚未执行、需要确认。无匹配、歧义、搜索失败、没有执行搜索要分别说明；不得统一说成“未找到”。旧 action ID 失效，新目的地必须新确认。当前取消导航的确认策略与 T10 冻结期望差异保持原样并继续披露。

## 可见验收与证据边界

两个任务分别有行为测试和独立提交。最终执行无密钥离线回放。父线程已进行 C04/X08/M03 × 两模型 × 各一次的修复前实测，原始证据保留在独立 before 目录；优先做同参数 after，逐条展示六组观察，不外推总体成功率。可选扩展为现有 batch CLI 对上述三项及 C01/R03/M01/T10 控制项每模型 2 次；它不阻塞既有 before/after 验收。使用已授权且实际配置的 provider/model，保留失败、超时、审核错误；如调用审核器，使用冻结 rubric。明确样本数与未覆盖项。

推荐公开一份简短中文结果页：已复现根因、实际修复前输入、修复后请求依据、目标候选/待确认状态，以及定向在线采样逐案例通过数。A6 120 分母数字继续保留为历史完整评测；定向采样与开发变体分开，不声称提升了完整 40 场景表现。原始请求、密钥、个人轨迹和本地绝对路径不进入公开产物。
