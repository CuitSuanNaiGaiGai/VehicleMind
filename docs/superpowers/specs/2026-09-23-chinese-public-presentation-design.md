# VehicleMind 中文介绍与演示设计

## 目标与边界

招聘者、演示观看者和项目使用者直接看到的介绍、操作说明、报告页面及终端提示统一使用简体中文。保留 VehicleMind、MediaPipe、YOLOPv2、PERCLOS、Git、JSON 等专有名词或通用缩写，首次出现时用中文解释。代码标识、工具名、枚举值、JSON 键、文件路径、哈希、许可证原文和引用元数据不翻译，不改变现有场景协议、trace schema 或 API。

本次覆盖 README、面向使用者的 `docs/offline_video_pipeline.md` 与 `docs/agent_pending_actions.md`（已有中文，仅检查一致性）、离线回放 `report.html`/`report.js` 的可见文字、示例场景的标题/说明/脚本化 Agent 回复、`replay_demo.py` 和离线视频入口的终端提示。`docs/superpowers/` 里的历史设计与实施记录属于内部工程资料，不做追溯性翻译；第三方许可证与引用保持原文。

## README 信息架构

当前 README 超过 1600 行，混合旧进度、英语标题和重复算法说明。重写为面向招聘者和复现者的中文首页：30 秒项目定位、当前可展示内容与限制、最短离线启动命令、系统模块与个人实现边界、验证证据入口、后续里程碑。保留有用的算法背景，但移入分主题的中文技术文档；删除过时、重复或与当前代码不符的宣传性表述，不丢失许可证、数据来源和运行前提。首页不能把录制观测写成实时模型推理，也不能把预训练模型接入写成原创算法。

## 报告展示层

- HTML 设置 `lang="zh-CN"`，标题、面板、状态徽章、指标名称、图片替代文字和限制提示改为中文。
- JavaScript 在展示层维护集中映射：上下文域、字段、观测质量键、事件/工具记录类别、常见枚举值和断言名称显示为中文；原始 `summary.json`、`trace.json` 不变。
- 时间线按记录类型输出中文摘要，而非直接把英文原始对象 `JSON.stringify` 后作为主内容展示。无法识别的字段保留原始键并明确标记为“未翻译字段”，避免静默误译；原始数据仍可通过结果包核对。
- `UNKNOWN`、`None`、stale、invalid 等要区分展示为“未知”“缺失”“已过期”“无效”，不得一律显示“正常”。成功/失败状态只翻译呈现文案，不更改机器可读的布尔值与错误码。
- 场景标题、描述和脚本化 Agent 回复改为中文；回放的事件顺序、工具调用、断言及最终状态保持原义。

## 终端和离线视频入口

回放与视频入口的帮助文案、状态、命令菜单、错误前缀、感知摘要和健康统计说明改为中文。命令本身（如 `context`、`health`、CLI 参数）保持兼容，显示时附中文解释；不要求用户修改现有自动化脚本。在线模型原始回复不强制翻译，不能在没有模型调用的情况下声称其输出始终是中文；可在提示词中要求中文回复并在文档中注明这一限制。

## 验收与证据

1. 零依赖离线场景可继续一条命令运行，所有断言通过，生成的报告主要可见文案为中文；`summary.json`、`trace.json` 的键、枚举与结构保持兼容。
2. README 首屏中文明确标注“录制观测回放”与“真实离线视频推理”的区别，并给出可复制的启动和查看结果命令。
3. 中英文显示映射有单元测试；报告生成测试检查中文标题、关键面板、状态与安全限制。失败场景也显示中文失败状态与原因。
4. 全套测试、格式检查、类型检查和文件长度门禁通过；不凭空补充感知精度或 Agent 成功率。
