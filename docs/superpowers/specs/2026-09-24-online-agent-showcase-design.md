# 在线 Agent 决策展示设计

## 目标与边界

为单次在线评测生成中文 `report.html`，让观众从录制观测、实际送入 LLM 的上下文、模型回复与工具请求，看到模拟车机结果。沿用 `trial.json` 作为唯一事实来源，不将录制观测称为实时视频推理，不将模型建议称为确定性安全裁决。

## 展示结构

首屏依次展示舱内关键量（持续闭眼秒数、近期哈欠、驾驶状态、风险）、舱外关键量（车辆/行人/骑行者、交通密度、车道和可行驶区）、用户请求、实际进入首轮模型消息的上下文摘要。随后展示逐轮模型回复、工具请求与执行结果、待确认/确认和最终模拟导航状态。缺失或无效数据明确显示“未提供/无效”，不可用最终上下文冒充模型当时收到的输入。若模型只建议音乐，应如实显示，不自动标记为安全替代方案。原始消息、响应和评分放入折叠区。

## 实现边界

新增独立的在线展示模块，负责从 EvaluationCase 与 TrialResult 投影展示数据、HTML 转义和页面生成；现有单次评测 `write_report` 同时输出 `report.html`，保留原 `trial.json` 与 `report.md`。不修改 Agent 决策、工具安全门或现有离线回放报告。页面仅使用本地 CSS，浏览器可直接打开。

## 验收

测试验证关键感知字段、首轮实际上下文、模型回复、工具及状态分别来自对应源；缺失字段和错误运行不会虚构事实；用户/模型文本不能注入 HTML。单次在线评测结束打印 HTML 路径。README 给出运行命令、来源限制和展示说明。
