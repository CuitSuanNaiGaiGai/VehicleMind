# A1：可靠上下文与任务状态验收记录

日期：2026-09-25

## 完成内容

- 每轮按请求路由舱内、舱外和车辆事实；播放音乐、导航、休息请求均关联驾驶风险、道路及车辆状态。
- 逐字段记录质量状态、来源、源时间、接收年龄和真实置信度。离线视频源时间与本机接收年龄分开；未提供的来源或置信度保持缺失。无效、过期字段不作为当前上下文发送。
- 用户自述、模型历史和工具返回以不同来源写入 task trace；给模型的历史块注明其为历史证据，不代表当前传感器状态。
- AgentTask 记录目标、任务 ID、状态变化、最近及完整工具结果、待确认动作和结果核对。支持执行中、等待输入、待确认、完成、失败、取消；过期确认、目标未命中与目标变更保留失败/等待原因。
- 增加 YAML 可配置的单轮预算：总时长 90 秒、模型请求的工具调用最多 10 次、最多 5 轮；对重复工具调用按名称和规范化参数去重。Qwen/GLM 请求携带剩余时间。预算按调用边界检查；同步本地扩展工具无法被强制中止。
- 工具 JSON 格式、对象类型、必填字段、额外字段、标量类型、范围和枚举均在执行前核验。无效参数不执行；模型错误、空回复、超时、预算耗尽、重复调用均留下确定的失败原因。
- 单例评测 CLI 默认采用 YAML 配置中的工具轮数预算；评审发现的可选参数 `None` 比较错误已修复并新增无在线 API 的 CLI 回归测试。
- 多轮澄清期间用户切换到不相关主题时，新建任务，不再把新问题并入旧任务目标。
- 写操作结果未知时不自动重放；根据媒体、空调或车辆操作调用专用只读状态工具核对，并将结果未知保留为“等待输入”。该只读核对有单次预算保留额。
- 在线 `trial.json`/HTML 报告记录每轮实际模型上下文、字段来源和任务状态；离线 replay trace 记录每轮任务状态。HTML 对状态、原因和逐轮事实提供中文展示，原始 JSON 可展开。

配置：[agent.yaml](../../modules/config/agent.yaml)。实现与测试拆分在 `modules/vehicle_ai/agent/`、`modules/vehicle_ai/evaluation/task_display.py` 和 `tests/vehicle_ai/test_agent_budget*.py`、`test_task_state.py`、`test_a1_trace.py`。在线接口默认使用该 YAML；单例和批量评测都可通过 `--agent-config`、`--turn-timeout-seconds`、`--max-tool-calls` 覆盖。
