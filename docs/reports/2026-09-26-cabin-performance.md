# 舱内感知性能与双域视频处理核验

## 结论

在本机 Apple M5（arm64）上，使用 MediaPipe Face Landmarker 对舱内 26 条视频逐帧处理 30,063 帧；全部视频成功。单帧服务耗时：首帧 P50/P95 为 **8.74/9.42 ms（n=26）**，首帧后的稳态 P50/P95 为 **4.38/4.86 ms（n=30,037）**。包括视频读取和核验记录开销的离线回放吞吐为 **204.19 FPS**（26 条成功视频、30,063 帧）。

这组结果支持“在固定本机样本上的处理性能可量化、可复跑”，**不代表感知准确率、实时摄像头性能或完整座舱 Agent 端到端延迟**。

## 样本覆盖

| 感知域 | 成功视频 / 尝试视频 | 处理帧 | 有效结构化输出帧 |
|---|---:|---:|---:|
| 舱内 | 26 / 26 | 30,063 | 30,063 |
| 舱外 | 26 / 26 | 22,809 | 22,809 |

两组视频均按冻结清单完整解码与推理，没有抽帧；结构化展示采样间隔为 30 帧。`有效结构化输出` 只表示模型服务返回了有效输出，**不表示结果正确**。

## 舱内处理性能

| 指标 | 样本数 n | P50 | P95 | 统计单位 |
|---|---:|---:|---:|---|
| Service Initialization Latency (服务初始化延迟) | 26 | 22.53 ms | 29.23 ms | 每条视频一次 |
| First-frame Latency (首帧处理延迟) | 26 | 8.74 ms | 9.42 ms | 每条视频首个处理帧 |
| Steady-state Frame Latency (稳态单帧处理延迟) | 30,037 | 4.38 ms | 4.86 ms | 每条视频首帧后的处理帧 |
| Offline Replay Throughput (离线回放吞吐) | 26 条视频 | **204.19 FPS** | — | 共 30,063 帧 |

服务初始化 P50/P95 为 22.53/29.23 ms，均值为 32.73 ms；本次最大值 279.84 ms，包含单进程首次导入依赖的额外开销。该初始化指标不能解读为任意冷启动环境的保证值。

### 计时口径

- 单帧首帧/稳态耗时直接读取感知服务的 `snapshot.metadata.processing_ms`；稳态统计从每条视频的第二个处理帧开始。
- 服务初始化耗时从创建舱内服务前开始，包含模型服务初始化；不计入离线回放吞吐。
- 离线回放 FPS = 有有效计时的成功视频处理帧数之和 ÷ 同一批视频的回放循环墙钟秒数之和。循环包括视频读取、逐帧感知和结构化结果更新，不包含服务初始化、关闭或报告渲染。
- 指标是单次本机运行的描述统计。逐帧样本存在时间相关性，不能把 30,037 帧当作 30,037 个独立驾驶场景。

## 限制与解释边界

- 使用的是 26 条舱内和 26 条舱外本地视频，未超过每域 50 条的项目规模；样本来源与许可状态尚未逐条核定，也没有对齐真值标签。
- 精度保持 `not_evaluated`。本报告不提供 Precision、Recall、F1、误报率或漏报率，也没有人工标注或消融实验。
- 视频可能来自相同场景或驾驶员，帧数与成功视频数都不能代替独立场景/驾驶员数量。
- 204.19 FPS 是当前固定环境下的**离线回放吞吐**，不是摄像头采集速率、UI 展示速率或车机端到端响应时间；本报告也没有覆盖 LLM/Agent 决策延迟。
- 原始逐帧时延、逐视频结果、视频与模型权重保存在本机被 Git 忽略的运行目录；公开仓库只提交本聚合报告，不包含视频、逐帧数据或本机绝对路径。
