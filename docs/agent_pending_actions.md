# Agent 待确认动作边界

敏感动作由 ToolRegistry 强制检查确认凭据。`PendingAction` 只保存一个待确认动作，确认必须携带其一次性 action ID；拒绝、目标变更或到期后，旧 ID 不能执行。

明确的 `取消`、`不要了`、`cancel`、`no thanks` 会在进入 LLM 前撤销待确认动作。以 `换成`、`改去`、`instead`、`change destination to` 开头且给出新目标的请求，会先撤销旧动作，再进入常规工具流程。新导航目标须由搜索工具返回与用户所说目标名称或预设别名匹配的规范 `poi_id` 才能成为待确认导航；不匹配或 LLM 直接编造的 ID 不会被暂存，Agent 会明确告知未创建待确认导航。当前离线搜索只返回固定的西湖服务区，因此其他目标不会假装解析成功。模糊表达不自动撤销，也不自动确认。

这些规则是确定性代码边界，不是提示词承诺。离线 scripted Agent 测试覆盖错误 ID、拒绝、改目标、到期边界和恶意工具调用；更多自然语言说法需在后续 Agent 自动化评测中单独统计。
