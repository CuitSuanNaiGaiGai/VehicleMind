# 项目证据与适用边界

VehicleMind 是面向感知算法与 Agent 编排岗位的可运行原型，不是量产车机软件。展示材料应明确区分下列证据：

1. **录制观测回放**：仓库内的示例场景可在无模型、无视频、无网络的环境复现，验证上下文更新、事件、Agent 回复、用户确认、模拟工具执行和安全断言。它不能证明感知准确率。
2. **真实离线视频**：需要用户提供本地舱内、舱外视频及模型权重，运行后才可展示实际感知输出。视频和权重不应误称为仓库内置资产。
3. **自动化评测**：Agent 可靠性应以明确场景集合、成功标准、失败类型、运行次数和可追溯结果量化。舱内和舱外感知样本各不超过 50 条，不做消融实验；不能把测试通过数解释成模型精度。

## 当前不应宣称的能力

- 回放报告不代表真实视频即时推理，也不代表端到端车机部署。
- 未经正式评测，不应填写识别准确率、Agent 成功率、延迟或资源占用数字。
- 项目没有实时采集前提；现阶段以离线视频为感知输入。模拟导航、车窗等工具不控制真实车辆。
- 驾驶员风险判断不能替代驾驶员注意义务、医学判断或任何安全认证。

## 复现与许可

核心回放和测试不需要 API Key；在线 Agent 仅在用户主动配置提供商时使用。运行结果应保留 Git 提交、解析后配置及配置哈希。带未提交改动的结果会标记为 dirty，不适合作为正式简历证据。
