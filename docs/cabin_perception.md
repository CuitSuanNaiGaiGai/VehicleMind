# 舱内驾驶员感知

舱内链路读取离线驾驶员视频或摄像头画面，先确定驾驶员是否在位，再提取面部关键点和眼口状态，按时间累计眨眼、持续闭眼、PERCLOS（一定时间窗口内的闭眼比例）与哈欠等证据。状态与风险是多帧判断，不应把单帧表情直接解释为疲劳驾驶。

## 实现与配置

- 面部关键点和眼口观测构成低层特征，时序证据与驾驶员状态判定分离，便于替换算法及检查阈值。
- 驾驶员状态及风险通过统一上下文进入事件层，Agent 消费的是状态和事件，不直接解析视频帧。
- 舱内阈值见 `modules/config/cabin.yaml`；原始代码与脚本入口见 `modules/cabin/`、`apps/cabin_demo/`。
- 运行本地离线视频与协同链路的操作见[离线视频演示](offline_video_pipeline.md)。视频和模型资产需要用户自行准备，权重不随仓库发布。

## 展示与验证边界

项目提供录制语义观测的可复现回放，它验证 Agent 编排，不执行本次舱内视频推理。真实视频演示必须使用本地视频与相应模型；两者的证据不能混用。舱内算法计划使用不超过 50 条样本进行小规模核验，指标仅在真实标注和实际运行结果形成后报告；当前不宣称疲劳识别准确率或车规级安全性。

公开驾驶员演示素材涉及 NITYMED，来源、引用与许可须按[第三方说明](../THIRD_PARTY_NOTICES.md)核对。使用其他视频时，也应确认采集授权和个人隐私处理方式。
